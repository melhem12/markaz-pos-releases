# Markaz POS — downloads

Installers and update files for **Markaz POS**, the offline-first point of sale and accounting app for Windows by [S-EMPIRE TECH](https://www.sempiretech.com/).

- **Download:** open [Releases](https://github.com/melhem12/markaz-pos-releases/releases/latest) and run `Markaz-POS-Setup-<version>.exe` (Windows 10/11, no administrator rights needed). If Windows shows "Windows protected your PC", click **More info → Run anyway**.
- **Updates:** installed copies check this page and update themselves.
